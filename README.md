# Student-Management-System
A console-based Student Management System developed in C. It allows users to add, view, search, update, and delete student records using file handling. The project demonstrates structures, functions, loops, conditional statements, and basic data management concepts.

# Student Management System

## Overview
This is a Student Management System developed in C. It is a menu-driven application that uses file handling to store and manage student records.

## Features
- Add Student
- View All Students
- Search Student
- Update Student
- Delete Student
- Count Total Students
- File Handling

## Technologies Used
- C Programming
- File Handling
- Structures
- Functions

## How to Run
1. Compile the program:
   gcc final_student_management_project.c -o student
2. Run:
   ./student
